# Copiloto de tráfego — G7Jurídico

Registro de trabalho do copiloto de Meta Ads. Tudo que for decidido, descoberto
ou quebrado entra aqui, com IDs, o número que sustentou a decisão e o que deu
errado e por quê.

- `contrato.md` — regras de trabalho, de segurança, de medição e armadilhas da API
- `ids.md` — IDs conhecidos, com origem (API ou usuário)
- `diario.md` — registro cronológico por sessão

Nenhum token, credencial ou dado pessoal de cliente entra nesta pasta.
